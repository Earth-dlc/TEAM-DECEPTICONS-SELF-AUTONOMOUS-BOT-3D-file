# 🤖 DAVIDPUTRA 3000 — 3D CAD & Mechanical Design
**Team Decepticons | Kalpataru Innovation Competition**

This repository contains the complete 3D mechanical assembly and chassis design for **DAVIDPUTRA**, an autonomous two-wheeled self-balancing pick-and-drop robot.

## 📁 Repository Contents

* **`.f3d` Source File:** The core 37 MB Autodesk Fusion 360 design file containing the full parametric assembly.
* **Chassis Architecture:** Multi-layer structural body, battery mounts, and rigid electronics housing optimized for a high center of gravity.
* **Manipulator Assembly:** Lightweight 2-DOF robotic arm and gripper mechanism designed to mount MG90S servos.
* **Actuator Mounts:** Custom brackets for the N20 geared DC motors.

## 🛠️ How to Use

To view, modify, or export standard 3D printing files (`.stl`, `.step`):
1. Download the `.f3d` file from this repository.
2. Open [Autodesk Fusion](https://www.autodesk.com/products/fusion-360/).
3. Click **File > Open > Open from my computer** and select the downloaded file.
